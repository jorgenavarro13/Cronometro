# ⏱️ Cronómetro Dinámico (JS Stopwatch) 🚀

## 📝 Descripción del Proyecto

El Cronómetro Dinámico es una aplicación web sencilla y funcional que permite **iniciar, pausar y resetear** el conteo de tiempo con precisión. Es un excelente ejemplo de cómo **JavaScript** gestiona la lógica temporal y realiza la **Modificación del DOM** para actualizar los dígitos en tiempo real.

---

## 🛠️ Tecnologías Utilizadas

| Tecnología | Propósito |
| :--- | :--- |
| **HTML** | Estructura base para el display y los botones. |
| **CSS** | Estilizado para un diseño limpio y legible. |
| **JavaScript** | Motor de lógica principal, control de tiempo (setInterval) y la **Manipulación del DOM**. |

---

## ✨ Características y Skills Destacadas

* **Lógica de Temporización:** Uso de `setInterval()` y `clearInterval()` para gestionar el flujo de tiempo (milisegundos, segundos, minutos).
* **Manipulación Dinámica del DOM:** Práctica de la habilidad clave de **actualizar el contenido de la página** (los dígitos del cronómetro) de manera continua y eficiente, sin recargar la página.
* **Control de Flujo de la Aplicación:** Implementación de lógica de estado (`start`, `pause`, `reset`) para asegurar que el cronómetro se comporte correctamente en cada interacción.
* **Interactividad con Event Listeners:** Los botones "Start", "Pause" y "Reset" están vinculados a funciones de JavaScript mediante *Event Listeners*.

## 🚀 Cómo Usarlo

No necesitas dependencias ni instalación.
Link a la github-page:

1.  **Clona el Repositorio:**
    ```bash
    git clone [https://github.com/jorgenavarro13/Cronometro.git]
    cd Cronometro
    ```
2.  **Ejecuta:**
    Abre el archivo `index.html` directamente en tu navegador.
3.  **Interactúa:**
    * Haz clic en **Start** para comenzar el conteo.
    * Haz clic en **Pause** para congelar el tiempo.
    * Haz clic en **Reset** para devolver el cronómetro a cero.
